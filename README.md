## 💬 W.I.L.L.O.W

![WILLOW](https://github.com/user-attachments/assets/012fd163-2d84-4eca-a087-9898475e7229)

W.I.L.L.O.W (Workflow Intelligent Localized Learning & Optimized Worker) is a self-hosted AI agent specifically designed to help you manage your envirornment. In this early version she acts as oracle that guides you through setting up containers. In addtiton she as a few built in intergrations with HomeAssitant & Jenkins. In future updates she will be able to install containers for you. 

- To install: once WAGMI is installed run: docker-compose up -d. This will install n8n & postgres. login to n8n and input the willow url to load the workflow and start WILLOW. more instructions here: https://medium.com/@webdevmike01/introducing-w-i-l-l-o-w-827c3e965ef6
