# Contributing

Contributions are welcome! Please read the [Awesome list guidelines](https://github.com/sindresorhus/awesome/blob/main/contributing.md) before submitting.

## Ways to Contribute

- Report bugs or suggest features by opening an issue
- Submit pull requests to the [WAGMIOS repository](https://github.com/mentholmike/wagmios)
- Help improve the documentation
- Suggest new marketplace apps
